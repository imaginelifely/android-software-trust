# Android Software Trust

A research project focused on assessing the security risk and trustworthiness of Android software using multiple sources of cybersecurity evidence.

## Overview

The project explores a multi-source evidence fusion approach that combines:

- **Static Evidence**
- **Behavioural Evidence**
- **Network Evidence**

Instead of relying on a single source of information, the framework combines these different types of evidence to estimate the overall risk associated with Android software.

The framework also explores **trust** and **disagreement** between the different evidence sources.

## Current Work

The current work focuses on:

- Dataset analysis and preparation
- Processing multiple cybersecurity evidence sources
- Multi-source evidence fusion
- Source weighting
- Risk assessment
- Ablation studies
- Robustness and sensitivity analysis

## Project Status

**Research / Experimental Stage**

This repository contains the ongoing implementation, experiments, and analysis for the project.

## Future Direction

The long-term goal is to develop an adaptive Android software trust assessment system that can incorporate changing evidence and dynamically assess software risk.
